# Academia GGPM

**Site institucional de uma academia | Projeto em equipe | SENAC São Paulo**

---

## Apresentação proj. GGPM

A **Academia GGPM** é um projeto educacional de desenvolvimento web que apresenta, em um único site, informações sobre uma academia, seus planos e atividades oferecidas.

Este foi o **último projeto que desenvolvi em grupo durante o curso básico de HTML e CSS no SENAC**. Ele representa uma etapa importante da minha formação inicial: além de aplicar os conhecimentos de estruturação e estilização de páginas, pude participar de um trabalho coletivo com diferentes seções integradas em uma mesma interface.

O repositório foi mantido como registro dessa experiência e da minha evolução no desenvolvimento web.

## Proposta do projeto

O objetivo foi construir um site institucional com navegação entre páginas e apresentação organizada de informações para possíveis alunos. A estrutura inclui:

| Página | Conteúdo |
| --- | --- |
| **Início** (`index.html`) | Apresentação da Academia GGPM, carrossel de imagens, informações sobre atividades e localização. |
| **Planos** (`planos.html`) | Exibição de modalidades de planos com descrições, atividades incluídas, duração e valores ilustrativos. |
| **Personal Trainer** (`personal-trainer.html`) | Informações sobre acompanhamento individual, objetivos de treinamento e formulário visual para dúvidas. |
| **Pilates** (`pilates.html`) | Apresentação da modalidade, explicações sobre as aulas e formulário visual de contato. |

**Observação:** trata-se de um projeto demonstrativo. Os preços, endereços, serviços e formulários são conteúdos de apresentação e não constituem uma oferta ou sistema real de atendimento.

## Tecnologias e recursos

- **HTML5:** estrutura e conteúdo das páginas.
- **CSS3:** aparência, cores, tipografia, espaçamento e organização visual.
- **Bootstrap:** componentes e sistema de grade usados na interface, incluindo o carrossel da página inicial.
- **JavaScript e jQuery:** bibliotecas e arquivos de scripts incluídos no projeto para suporte aos componentes da interface.

A estrutura HTML inclui referências ao **LayoutIt!**, ferramenta utilizada na geração de parte da marcação inicial do layout.
